# Building and running SSOS with pixi

[pixi](https://pixi.sh) provides a single, reproducible, lockfile-pinned
environment for Space Station OS. ROS 2 Jazzy comes from the
[RoboStack](https://robostack.github.io) conda channel, so you do not need a
system ROS install, `apt`, or `rosdep`. The environment (ROS, build tools, and
the GUI's Python dependencies) is described by `pixi.toml` and pinned by
`pixi.lock`.

## Scope

The current SSOS stack:

- `space_station` — mission-control GUI
- `ssos_core` — system manager
- `ssos_sim` — simulation controller (`/clock`, `time_scale`, fault injection)
- `ssos_eclss` — ECLSS physics + nodes

## Prerequisites

- [pixi installed](https://pixi.sh/latest/#installation)
- Linux (`linux-64`). macOS/Windows are not covered yet.
- Network access to `prefix.dev` and `conda-forge` for the first `pixi install`.

## Usage

```bash
pixi install        # resolve + fetch the environment (first run only)
pixi run build      # colcon build the SSOS packages
pixi run station    # launch GUI + core + sim + eclss
```

| Task | What it does |
|------|--------------|
| `pixi run build` | `colcon build --symlink-install --packages-up-to space_station ssos_core ssos_sim ssos_eclss` |
| `pixi run station` | source the overlay + `ros2 launch space_station space_station.launch.py` |
| `pixi run gui` | source the overlay + `ros2 run space_station space_station` |
| `pixi run test` | `colcon test --packages-select ssos_eclss` + result summary |
| `pixi run clean` | remove `build/ install/ log/` |

The ROS 2 environment is activated automatically by pixi (RoboStack packages
carry their activation scripts); the `station`/`gui` tasks additionally source
the local `install/` overlay.

## Channels

`pixi.toml` uses `robostack-jazzy` (first) then `conda-forge`. Keep that order;
do not add the `defaults` channel (RoboStack is incompatible with it).

## Notes and known risks

- **RoboStack Jazzy coverage.** The first `pixi install` on a networked machine
  is what confirms every `ros-jazzy-*` dependency resolves. If a package is
  missing on `robostack-jazzy`, either add its correct name or fall back to
  `ros-jazzy-desktop` (broad meta) while the specific set is sorted out.
- **Custom messages.** `space_station_interfaces` (msgs, srvs, actions) is
  generated by the RoboStack `rosidl` toolchain during `pixi run build`.
- **Qt + OpenGL.** The GUI uses PyQt5 (`pyqt`), `pyqtgraph`, and `pyopengl`
  (GNC 3D view). Rendering from the conda env depends on the host GL driver;
  verify on the target machine.
- **Slimming.** `ros-jazzy-ros-base` plus the explicit message/lifecycle packages
  keeps the environment lean. Swap to `ros-jazzy-desktop` only if you need the
  broader toolset.
